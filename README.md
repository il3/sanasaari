# Sanasaari

Selaimessa pelattava oppimispeli alakoulun 6. luokalle. Pelaaja purjehtii saaristossa ja ratkaisee matikan ja suomen kielen tehtäviä. Vene täyttyy laatikoista, kun vastaa oikein, ja seuraava saari aukeaa.

- Yksi tiedosto (`index.html`), ei asennusta eikä riippuvuuksia.
- Edistyminen tallentuu selaimen localStorageen.
- Fontit tulevat Google Fontsista, ja ne ovat ainoa ulkoinen resurssi.

## Pelaaminen paikallisesti

Avaa `index.html` selaimessa.

## Julkaisu GitHub Pagesilla

Repositoriossa: Settings → Pages → Source: "Deploy from a branch" → Branch: `main`, kansio `/ (root)`.
Sivu aukeaa osoitteeseen `https://<käyttäjä>.github.io/<repo>/`.
